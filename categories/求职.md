- Include a specific, quantifiable result where possible

## 14. 面试离职原因应答策略

**Prompt：**
```
请帮我准备"离职原因"面试应答：

我的真实离职原因：[如 晋升受限/薪资/文化不合/裁员]
目标岗位：[岗位与公司]
简历中的离职时间线：[入职-离职时间]

输出：
1. 应答原则（真实但不抱怨、聚焦未来、避免贬低前雇主）
2. 3 个版本的回答（1分钟版/30秒版/追问深挖版）
3. 常见追问及应对（"是不是被裁的""和领导有矛盾吗"）
4. 表达"为什么选择新公司"的连接句
5. 语气与体态建议（面试场景）
```
> 📅 2026-08-02
> 来源：AI Academy — 求职面试提示词 2026（整理）
> 用法：离职原因=简短事实+积极转向，把"离开"讲成"选择"。

## 15. 职业空窗期面试应答策略

**Prompt：**
```
请帮我准备"职业空窗期"的面试应答：

空窗时长：[如 8 个月]
空窗期经历：[学习/照顾家人/旅行/自由职业/求职本身]
目标岗位：[岗位]

输出：
1. 应答框架（承认空窗→做了什么→获得了什么→如何衔接岗位）
2. 把空窗经历"翻译"成岗位相关能力的 3 种说法
3. 避免的说法与陷阱（过度道歉/编造经历）
4. 简历上空窗期的呈现方式建议（时间线写法）
5. 追问应对："这段时间为什么这么长"
```
> 📅 2026-08-02
> 来源：AI Academy — 求职面试提示词 2026（整理）
> 用法：空窗期不是减分项，关键是展示这段时间的成长与衔接逻辑。
