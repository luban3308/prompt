## 1. AI 游戏机制设计

**Prompt：**
```
Design a core game mechanic for:

Game concept: [游戏概念]
Genre: [2D platformer / puzzle / RPG / strategy]
Target platform: [mobile / browser / desktop]

Specify:
1. Core loop (what the player does repeatedly)
2. Input method (tap, click, keyboard, drag)
3. Trigger condition (when does this mechanic activate?)
4. Result (what happens visually and in game state)
5. Progression (how does this mechanic evolve?)
6. Failure state (what happens when the player fails?)
7. Juice elements (screen shake, particles, sound)

Format as a game design document snippet.
```
> 📅 2026-07-28
> 来源：Summer Engine — How to Make a Game With AI Prompts 2026
> 用法：逐个机制设计而非一次性"生成整个游戏"，每个机制独立可测试。

## 2. 像素艺术资产生成

**Prompt：**
```
Generate a [size] pixel art asset for a [game genre]:

Asset type: [character / enemy / item / tile / UI element]
Subject: [具体描述]
Style: [retro 8-bit / 16-bit / modern pixel]
Color palette: [限制色板或留空]
View: [front-facing / top-down / isometric / side view]

Specifications:
- Transparent background
- Consistent with [existing art style if any]
- Animation frames if applicable (idle, walk, attack)

Provide a detailed text description of the visual that can be used as a prompt for pixel art generation tools.
```
> 📅 2026-07-28
> 来源：Summer Engine / Reddit r/generativeAI — Game Asset Prompts 2026
> 用法：为游戏资产生成详细的文本描述，供 AI 图像工具或像素画师使用。

## 3. 游戏关卡布局设计

**Prompt：**
```
Design a level layout for:

Game genre: [platformer / puzzle / shooter / racing]
Level theme: [主题]
Difficulty: [early-game / mid-game / boss / tutorial]
Target play time: [X minutes]

Provide:
1. Level map description (text grid or flow diagram)
2. Key gameplay moments (introduction → escalation → climax → reward)
3. Enemy/obstacle placement with pacing rationale
4. Collectible/secret locations
5. Difficulty curve (where spikes and rests occur)
6. Visual landmarks for player orientation
7. What the player learns in this level
```
> 📅 2026-07-28
> 来源：Medium — Create a Full Game with One AI Prompt in 2026
> 用法：游戏关卡设计，含节奏曲线和教学机会规划。
