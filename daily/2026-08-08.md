# 2026-08-08 热门 AI 提示词（54 个）

## 1. 推理模型目标式提示法

**Prompt：**

```
解决以下问题：[问题背景与约束]

要求：
- 直接给出结果，不需要输出详细推理步骤
- 完成后用两句话简短说明你的判断依据
```

> 来源：Data-DI 部落格 — 越下指令 AI 越笨？2026 提示詞技巧全面升級
> 用法：推理模型（GPT-5.5/Gemini 3.1 Pro 等）下说目标不说步骤，让模型自己选解题路径；旧式「请一步步思考」反而拖累表现。
---

## 2. 推理力度参数调优（Reasoning Effort）

**Prompt：**

```
你是提示工程顾问。针对以下任务推荐推理力度（Reasoning Effort）参数：

任务类型：[简单问答/代码生成/数学证明/长链多步分析]
延迟与成本预算：[低/中/高]

推理力度分级：none / low / medium / high / xhigh

请给出：
1. 推荐等级（默认建议 none~medium，xhigh 仅用于极致推理长链任务）
2. 每个等级适合的任务类型
3. 需要升级/降级的判断信号
4. 各等级的 A/B 测试建议
```

> 来源：Data-DI 部落格 / OpenAI 2026 提示词指南（Test-Time Compute）
> 用法：2026 年提示词已从纯文字技巧变成「文字技巧+参数设定」双轨并行，把推理力度当可调参数，避免无谓延迟与成本。

## 3. 思考假设先行提示法

**Prompt：**

```
在开始回答之前，先列出你对这个问题的所有假设：
1. 你对任务背景的理解
2. 你默认的已知信息
3. 你无法确认、需要我补充的点

列出假设后再给出答案；并说明若某条假设不成立，答案需要如何修正。
```

> 来源：Data-DI 部落格 — 2026 提示词技巧：让模型说出它的「思考假设」
> 用法：一句咒语让 AI 先讲假设再解题，避免用错误前提得出漂亮但错误的答案。

## 4. 零样本优先、格式不符再补范例

**Prompt：**

```
请分析以下输入，依据这些原则产生输出：
[原则1]
[原则2]
[原则3]

输出格式：[期望格式]

注意：先不要给我范例，直接处理；如果输出格式不符合预期，我会再补范例给你。
```

> 来源：Data-DI 部落格 / OpenAI 2026 提示词指南（Few-shot 顺序调优）
> 用法：推理模型通常不需要范例也能出好结果；先零样本、格式不对再补范例，顺序比数量重要。

## 5. 反例约束清单法（Do NOT include）

**Prompt：**

```
[任务描述]

Do NOT include:
- 空泛的套话与陈词滥调
- 模棱两可的措辞（可能/或许/大概）
- 与任务无关的补充信息
- 讨好式开场（"当然！""这是一个好问题！"）
- 超出范围的建议

完成后自查：若输出包含以上任一元素，删除后重新输出。
```

> 来源：buldrr — Best Claude Prompts 2026（Rule 3：负向约束）
> 用法：Claude 对负向约束的遵循最稳定，加「不要包含」清单能系统性去除 AI 味的填充与套话。

## 6. CRISP 提示框架

**Prompt：**

```
角色背景（Context）：[场景与背景信息]
角色设定（Role）：你是一名[专业角色]
指令（Instruction）：[要做的具体任务]
规格（Specification）：[输出格式、长度、结构]
目的（Purpose）：[这份输出的用途/目标受众]

请严格按以上五要素输出，缺一不可。
```

> 来源：PromptPrepare — How to Write the Perfect AI Prompt (2026 Guide)
> 用法：CRISP = Context / Role / Instruction / Specification / Purpose，跨 ChatGPT、Claude、Gemini 通用，比开放式提问立竿见影。

## 7. 提示词 0-5 快速评分表

**Prompt：**

```
评估以下草稿输出，按 4 个维度打分（0-5）：

- Correctness 正确性：事实与逻辑无误
- Completeness 完整性：覆盖所有要求
- Clarity 清晰度：无歧义、易读
- Actionability 可执行性：下一步具体可落地

任一维度 < 4 分：修订一次后重新评分。
草稿：[粘贴输出]
```

> 来源：Prompt Builder — Prompt Engineering Best Practices 2026（Quick rubric）
> 用法：快速量化评估输出质量，低分自动触发一次修订，适合批量验证提示词效果。

## 9. 资料不足标注法（不脑补）

**Prompt：**

```
请基于我提供的资料回答：[问题]

规则：
- 资料中没有提到的内容，直接标注「资料不足」，不要用常识脑补
- 需要计算时，说明你使用的数据来源
- 不确定的数字标注 [估算]
```

> 来源：欸那個AJ — 2026 AI 提示词最佳设计指南
> 用法：明令禁止脑补，AI 就不会凭空创造，适合事实核查、文档分析与尽调场景。
