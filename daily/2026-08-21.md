## 1. 结构化标签链式提示

**Prompt：**
```
请把以下任务拆成 3 个步骤，每个步骤用 <step> 标签包裹输出，
下一步必须引用上一步的输出，最后汇总成最终结果。

<step1> [任务的第一步：如收集/分析] </step1>
<step2> [基于 step1 输出的第二步：如整理/提炼] </step2>
<step3> [基于 step2 输出的第三步：如成稿/决策建议] </step3>

任务：[粘贴你的任务]
```
> 来源：数位时代 BNext — 2026 最新提示词 7 原则（结构化标签、链式提示、类比任务）
> 用法：链式提示把大任务切成小步骤、逐步传递输出；结构化标签让模型清楚每段内容的边界，全平台通用。

## 2. 类比任务提示法

**Prompt：**
```
请用类比的方式来理解并完成这个任务：

我要做的新任务：[描述新任务]
这类似于你熟悉的一个任务：[描述熟悉的同类任务]

请先说明两者在结构上的对应关系，然后按照熟悉的那个任务的
处理方式来完成新任务，并标注哪些地方需要调整。
```
> 来源：数位时代 BNext — 2026 最新提示词 7 原则
> 用法：把陌生任务映射到模型熟悉的同类任务上，降低理解成本，输出更贴合预期。

## 3. Gemini 五步短提示结构

**Prompt：**
```
1. Define the task in one sentence. [一句话定义任务]
2. Set the scope (time range, region, source type). [限定范围：时间/地区/来源类型]
3. Name the output format in one line. [一行说明输出格式]
4. Ask for source links for factual claims. [事实性陈述要求附来源链接]
5. Flag uncertainty instead of guessing. [不确定就标注，不要猜测]

Task: [你的任务]
```
> 来源：Prompt Builder — Best AI for Prompt Engineering 2026 (Claude vs ChatGPT vs Gemini)
> 用法：Gemini 在提示词短、范围明确、输出格式清楚时表现最好；五步结构适合快速、事实类任务。

## 4. 专业简报式提示

**Prompt：**
```
Write a [format] for [specific audience].
Goal: [clear outcome]
Length: [exact or narrow range]
Must include: [key elements]
Must avoid: [topics, phrases, or angles]
Tone: [brief description]

Content/topic: [你的主题]
```
> 来源：eWeek — 7 Best ChatGPT Writing Prompts for 2026
> 用法：像给专业写手发简报（brief）一样写提示词：目标、长度、必含、必避、语气五要素，减少泛泛输出。

## 5. 提示词调试法

**Prompt：**
```
请帮我调试这个提示词（像调试代码一样）：

当前提示词：[粘贴你的提示词]
期望输出：[描述你想要的输出]
实际输出：[粘贴实际输出，说明哪里不对]

请按以下步骤处理：
1. 诊断：这个提示词哪里出了问题（具体指出）
2. 只修改一个变量：给出改动最小的一版改进
3. 预期效果：说明这一处改动为什么能改善输出
4. 变体：再给 2 个不同方向的替代写法
```
> 来源：JetBrains Developer Advocate Vitaly Bragilevsky — How to Write Better AI Prompts as a Software Developer in 2026
> 用法：提示词效果不好不要整段重写，像调试代码一样一次只改一个变量，并保存可复用的提示词片段。

## 6. 角色+受众双定位解释提示

**Prompt：**
```
Act as a [expert role, e.g., cybersecurity analyst] explaining [topic, e.g., zero trust security] to a [specific audience with limited experience, e.g., small business owner].

请基于这个角色和受众：
- 收敛语气、词汇和细节深度
- 避免泛泛而谈
- 用受众能听懂的类比
- 先讲清楚为什么重要，再讲是什么、怎么做
```
> 来源：eWeek — 10 AI Prompting Tips That Improve ChatGPT, Claude, and Gemini Results (2026)
> 用法：同时定义角色和受众，模型会收敛语气、词汇和信息密度，显著减少通用回答。

## 15. 真诚道歉信

**Prompt：**
```
Write a sincere apology to [person] for [what happened].

Rules:
- Own the action completely — no "I'm sorry if you felt..."
- No excuses, no justifications, no blame-shifting
- No plea for forgiveness (don't make them do emotional work)
- State what you will do differently, concretely

Context: [what happened and why it matters]
```

> 用法："不乞求原谅"是最难也最关键的一条：道歉者承担全部责任，不让被伤害方做情绪劳动。
