## 1. 推理模型提示：先零样本后补例

**Prompt：**
```
2026 年推理模型（GPT-5.x / Claude Opus / Gemini Pro）官方建议：先不喂示例。请直接按以下方式处理我的任务：

1. 先基于以下原则直接给出输出：〔原则1〕、〔原则2〕
2. 不要一开始就套用示例格式
3. 如果输出格式不符合预期，我会再补充 1-2 个示例，届时请严格对齐示例格式

任务：[任务描述]
```
> 来源：OpenAI 2026 Prompt Guide（经 Data-DI 博客转述）
> 用法：推理模型自带拆解能力，先给原则式指令而非旧式 few-shot，避免把模型框死；格式不对再补例。

## 2. 推理强度与详细度双旋钮

**Prompt：**
```
请分别用两组参数设置处理同一个任务，并对比输出：
- 推理强度（reasoning_effort）：低 / 高
- 详细度（verbosity）：简洁 / 详尽

任务：[任务描述]

先说明你对每组组合的预期差异，再输出"低+简洁"与"高+详尽"两个版本。
```
> 来源：Data-DI — 2026 提示词技巧全面升級
> 用法：把"怎么问"和"调多深"分开；执行型任务用低推理+简洁，跨文档研究型任务再调高。

## 3. 先说假设再解题

**Prompt：**
```
解决以下问题：[问题背景与数据]

在给出答案前，先列出你的关键假设（至少 2 条，例如数据口径、时间范围、边界条件）。
完成解答后，用两句话说明你的判断依据。
```
> 来源：Data-DI / 经理人 2026 Prompt 全攻略
> 用法：让模型暴露假设而非隐藏；对推理模型，"先讲假设再解题"比笼统的"一步步思考"更稳。

## 4. 自我一致性多数表决

**Prompt：**
```
这个问题很关键，请用 3 种不同的解题路径分别求解（例如不同公式、不同切入角度、不同资料口径），然后：
1. 列出每种路径的答案
2. 指出哪些路径结论一致
3. 给出出现次数最多的答案作为最终结论
4. 说明其余路径为什么可能出错

问题：[问题]
```
> 来源：Reddit r/PromptEngineering — The AI prompting tricks that actually matter in 2026
> 用法：对数学、逻辑或高风险决策，用"多路径+多数表决"捕捉模型第一遍的自信错误。
