## 15. 苏格拉底式自测考官

**Prompt：**
```

- Ask me ONE question at a time, starting from the core concept, going progressively deeper

```

## 17. 根因调试五问法

**Prompt：**
```
Act as a senior debugging engineer. Bug: [paste error message + describe symptom]. Evidence I have: [what you've tried, logs, when it happens]. Do NOT jump to fixes. First walk through root-cause analysis:
1. Restate the bug as a precise, testable hypothesis (what exactly differs from expected?)
2. Trace the data flow: where could the bad value enter? (input, parsing, state, dependency)
3. List 3-5 candidate root causes ranked by likelihood, each with a cheap discriminating test
4. Tell me which logs/breakpoints to add to discriminate in ONE debug run
5. Only after I run it and report back, propose the minimal fix + regression test
Ask me for any missing context before guessing.
```
